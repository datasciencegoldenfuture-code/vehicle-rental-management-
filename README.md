# 🚗 Vehicle Rental Management System

A console-based **Vehicle Rental Management System built with Python**. This project allows an admin to manage vehicles, rent and return vehicles, calculate rental bills, add new vehicles, and view rental history.

## ✨ Features

- 🔐 Admin Login
- 🚘 View Available Vehicles
- 📝 Rent a Vehicle
- 🔄 Return a Vehicle
- ➕ Add New Vehicles
- 💰 Automatic Rental Bill Calculation
- 📜 View Rental History
- 🚪 Exit System

## 🛠️ Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
- User Input
